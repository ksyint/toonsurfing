## 통합 중 수정한 사항

1. **인증정보:** 두 저장소에서 OpenAI 키 2개를 발견했습니다. 현재 파일뿐 아니라 관련 과거 커밋·메시지에서도 제거했고 런타임은 `OPENAI_API_KEY`를 읽습니다. 이미 원본에 노출된 키는 소유 계정에서 폐기·재발급해야 합니다. 원본 조직 저장소 자체는 수정하지 않았습니다.
2. **중복:** 독립 Pic2Word 저장소의 985개 파일이 API 안의 복사본과 동일했습니다. 공통 경로로 정리하고 API의 고유 모델·다운로드 스크립트는 보존했습니다. 통합 이전 파일은 import 태그에 남아 있습니다.
3. **누락 UI 이미지:** 모든 원본 브랜치에서 `src/assets`가 제외되어 React 빌드가 불가능했습니다. 기존 배치를 유지하면서 누락된 로고·버튼·표지에 기본 SVG 18개를 추가했습니다. 원본 디자인 이미지를 복원한 것은 아닙니다.
4. **서비스 경로:** 특정 외부 IP 대신 환경변수와 로컬 프록시를 사용합니다. 검색 결과 컷은 API의 `/images`에서 제공합니다. 존재하지 않는 컷의 이미지 오류가 무한히 재시도되던 처리는 제거했습니다.
5. **시작 의존성:** `secret.txt`를 필수로 열던 동작을 제거했습니다. LaBSE 인스턴스와 FAISS DB를 캐시하고 API용 Pic2Word 모델을 실제 검색 시 로드합니다. FastAPI의 Gradio 자기 호출을 직접 함수 호출로 정리했습니다.
6. **호환성:** 컷 추출의 `typing.override`를 `typing_extensions.override`로 변경하여 Python 3.10에서도 가져올 수 있게 했습니다. 연결되지 않은 옛 React 라우터는 존재하지 않는 화면을 가져오므로 삭제했습니다.
7. **운영 단위:** 공통 Makefile, 분리한 의존성 명세, Python 3.10용 API 잠금 파일, 환경변수 예시, 이력 검증·인증정보 검사, GitHub Actions를 추가했습니다.

## 데이터와 외부 자산

- CLIP 인덱스 메타데이터에는 **15,309개**, 1,024차원 이미지 벡터가 기록되어 있습니다. 검색 코드는 결과 경로의 마지막 두 구성요소를 회차·컷으로 사용합니다.
- API에는 장면 설명 940개와 대사 데이터 732개가 포함되어 있습니다. `dialogue_search/dialogue_data.json`도 같은 대사 데이터입니다.
- 전체 원본 컷 데이터는 없습니다. 연구용 샘플과 컷 추출 샘플을 보존했으며, 실제 서비스는 원본 데이터 위치를 설정해야 합니다.
- Pic2Word 모델은 **1,723,251,477바이트**, 토크나이저는 **1,356,917바이트**인 Git LFS 객체입니다. 원본 LFS SHA-256을 그대로 사용합니다.
- CLIP의 약 67MB FAISS 인덱스와 약 31MB 임베딩 파일은 원본 Git 이력과 함께 보존했습니다.

## 남아 있는 원본 제약

- `image_retrieval`은 구현이 없습니다. 이름만으로 완성된 검색 모듈로 취급하면 안 됩니다.
- `dialogue_search/sim.py`는 `all_doc` 딕셔너리를 기대하지만 저장된 JSON은 리스트입니다. `web_ocr.py`와 `mask.py`에는 `/root/CartoonSegmentation` 절대경로가 남아 있습니다. 운영 API는 이 연구 스크립트를 사용하지 않습니다.
- `apps/api/text_retrieval_merged.py`는 예전 독립 API 실험이며 현재 진입점은 `demo.py`입니다. 예전 파일의 상대 데이터 경로를 현재 서비스 구성으로 간주하면 안 됩니다.
- Pic2Word는 요청마다 대상 이미지 특징을 다시 계산하고 CUDA를 직접 사용합니다. 전체 데이터에 적용하면 시간·메모리 문제가 생길 수 있습니다. 학습·평가 옵션과 KoLLaVA의 외부 모델 조합은 이번에 학습·추론으로 검증하지 않았습니다.
- API는 외부 번역 서비스, OpenAI, CLIP 서비스 및 데이터에 의존합니다. 모델·전체 데이터·새 키를 모두 준비한 실제 검색 품질 검증은 별도 작업입니다.
- 프런트엔드는 소녀재판만 선택 가능한 원본 동작을 유지합니다. 표지의 기본 SVG는 원본 아트워크 확보 후 교체할 수 있습니다.
- 기존 CRA 기반 빌드를 유지했으며 프레임워크 교체와 전체 패키지 현대화는 포함하지 않았습니다.

## 라이선스

Pic2Word의 Apache-2.0 `LICENSE`, 각 소스의 저작권 헤더와 OpenCLIP 라이선스를 유지했습니다. 나머지 원본 저장소에는 GitHub API 기준 라이선스가 지정되지 않았습니다. 전체 통합 저장소는 비공개로 생성합니다.
